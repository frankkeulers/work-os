Shortcuts work anywhere except while you are typing in a field.

## Everywhere

| Key | Does |
|---|---|
| `?` | Open this page |
| `[` | Collapse or expand the sidebar |

## Inbox

| Key | Does |
|---|---|
| `j` / `k` | Next / previous item |
| `o` | Open the item as a full page |
| `Esc` | Close the item panel |

## Item

| Key | Does |
|---|---|
| `e` | Done |
| `E` (shift-e) | Done and open the next item |
| `s` | Snooze |
| `c` | Correct triage |

## Guide

| Key | Does |
|---|---|
| `/` | Search the guide |
| `Enter` | Open the first search result |
| `Esc` | Clear the search |
