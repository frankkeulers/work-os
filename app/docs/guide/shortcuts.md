Shortcuts work anywhere except while you are typing in a field. Press `?` to see the keys for
where you are: a batch, a draft, the item, the list or the guide. `Esc` or `?` closes it.

## Everywhere

| Key | Does |
|---|---|
| `?` | Show the keys for where you are, with a link to this page |
| `[` | Collapse or expand the sidebar |
| `z` | Undo the last thing a toast offered to undo, even once it has gone; again to go further back |

## Inbox

| Key | Does |
|---|---|
| `j` / `k` | Next / previous item: Now, Today, To file, then This week |
| `g` then `n` | The first item in Needs you |
| `g` then `l` | The first item in Later (To file, or This week) |
| `t` | Today or tomorrow in the time column (on a wide screen) |
| `o` | Open the item as a full page |
| `Esc` | Close the item panel; with it closed, go back from a list opened in Later |

## Item

| Key | Does |
|---|---|
| `e` | Done |
| `E` (shift-e) | Done and open the next item |
| `s` | Snooze; then a number picks a time, or `s` again the suggested one |
| `c` | Correct triage |
| `y` | Triage was right: keep the decision as a label |
| `r` | Reply in the source: open the thread, email or chat |
| `f` | File to Confluence: open the draft, starting it if needed |
| `v` | File to the vault: open the draft, starting it if needed |
| `a` | Add to-do: your open steps, as tasks in your Tasks note |
| `→` | Skip, while filing in a batch: the item stays in To file |

## Draft

| Key | Does |
|---|---|
| `⌘↵` | Approve; while editing, save the edit and approve |
| `x` | Discard the draft |

## Guide

| Key | Does |
|---|---|
| `/` | Search the guide |
| `Enter` | Open the first search result |
| `Esc` | Clear the search |
